## 🌟 About GRANTLY

GRANTLY is a smart and user-friendly scholarship platform designed to help students discover scholarships, check eligibility, manage applications, and never miss important deadlines.

The platform simplifies the scholarship search process by bringing useful scholarship information and application management features into one place.

## ✨ Key Features

- 🎓 **Scholarship Discovery** – Explore available scholarships.
- 🔍 **Smart Search** – Search and filter scholarships.
- ✅ **Eligibility Checker** – Understand scholarship eligibility requirements.
- 📌 **Save Scholarships** – Bookmark scholarships for later.
- 📝 **Application Management** – Track submitted applications.
- ⏰ **Deadline Reminders** – Stay updated about upcoming deadlines.
- 📊 **Student Dashboard** – View scholarship and application information.
- 👤 **User Profile** – Manage personal and academic details.

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/USERNAME/GRANTLY.git
```

### 2. Navigate to the project

```bash
cd GRANTLY
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

### 5. Open in browser

Visit the local URL displayed in your terminal.
