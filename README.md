## 🌟 About The Project

**GRANTLY** is a smart scholarship discovery and management platform designed to help students find suitable scholarships, understand eligibility, manage applications and track important deadlines.

Our goal is to make scholarship opportunities easier and more accessible for every student.

## 🚀 Features

| Feature | Description |
|---|---|
| 🎓 Scholarship Discovery | Explore scholarship opportunities |
| 🔍 Smart Search | Search and filter scholarships |
| ✅ Eligibility Checker | Check eligibility requirements |
| ❤️ Save Scholarships | Bookmark interesting scholarships |
| 📋 My Applications | Track scholarship applications |
| ⏰ Deadline Reminders | Never miss an important deadline |
| 📊 Dashboard | Monitor scholarship activities |
